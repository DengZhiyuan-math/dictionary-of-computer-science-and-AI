第 17 讲。计算机网络：一次网页请求经历什么。

网络是多台设备传输数据的基础。IP Address，IP 地址，负责标识网络中的通信端点。Packet，数据包，是网络传输的数据单位。Router，路由器，负责把数据包朝目的地转发。DNS，域名系统，把人类易读的域名解析到相关网络地址。

TCP 和 UDP 是常见传输协议。TCP 提供面向连接、可靠、按序的字节流传输。它通过确认、重传、流量控制和拥塞控制等机制实现可靠性。UDP 比较简单，以数据报方式发送，协议本身不保证可靠送达或按序到达。实时游戏、视频通话等场景可能使用 UDP，并在应用层根据需要增加自己的机制。HTTP/3 所使用的 QUIC 也是基于 UDP 构建，但在更高层提供可靠性和安全等能力。

HTTP 是浏览器与服务器交换请求和响应的主要应用层协议。HTTPS 指在安全传输层保护下的 HTTP，现代互联网通常通过 TLS 实现加密与身份认证。HTTP 状态码中，200 表示成功，404 常表示资源不存在，500 表示服务器内部错误。GET 常用于读取，POST 常用于提交数据，PUT 和 PATCH 常用于更新，DELETE 常用于删除；具体行为仍取决于 API 的设计。

一个简化的网页访问过程是这样的。用户输入网址，设备使用 DNS 查找地址，然后建立必要的网络连接和安全会话，发送 HTTP 请求，服务器处理请求，可能访问数据库，最后返回 HTML、JSON 或其他资源。浏览器再加载样式、脚本和图片，渲染页面。

REST 是一种围绕资源设计 API 的风格；GraphQL 允许客户端描述所需数据；gRPC 是一种常用于服务间通信的远程过程调用框架。WebSocket 支持在一个连接中进行持续的双向通信，适合聊天、协作编辑或实时推送。API 不等于 HTTP；HTTP 只是实现 API 的常见方式之一。

Latency 是往返等待或响应时间，Bandwidth 是链路可传输的数据量，Throughput 是实际完成的数据传输量。CDN，内容分发网络，把内容缓存到离用户更近的位置。Load Balancer，负载均衡器，把请求分配给多个服务实例。Reverse Proxy，反向代理，代表服务器接收并转发客户端请求。Firewall，防火墙，依据规则限制网络流量。

Retry，重试，是出错后重新请求。Timeout，超时，防止无限等待。Exponential Backoff，指数退避，是每次失败后延长等待时间，避免所有客户端同时重试。Idempotency，幂等性，意味着把同一个操作重复执行，最终效果和执行一次相同。支付服务为什么经常需要幂等请求编号？因为网络超时之后客户端可能重试，但不能因此重复扣款。

网络领域还有 Authentication 和 Authorization。前者认证你是谁，后者决定你能做什么。OAuth 2.0 是授权框架。JWT 是一种承载声明信息的令牌格式，而不是安全认证流程的全部。Encryption 是加密，可在拥有合适密钥时还原；Hashing 是哈希摘要，通常不可逆；Digital Signature 是数字签名，用于验证来源与完整性。
