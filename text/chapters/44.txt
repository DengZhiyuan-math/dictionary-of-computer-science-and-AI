第 44 讲。一次训练到底发生什么：Batch、Step、Epoch 与反向传播。

Forward、Backward、Optimizer Step

前向传播把输入变成预测。损失函数把预测与目标比较。反向传播计算各个参数对损失变化的影响，也就是梯度。优化器再依据这些梯度和自身状态更新参数。反向传播负责算梯度，不等于更新参数；Adam 和 SGD 是更新方法，不是计算网络结构的替代品。这条链条是听懂训练代码的基础。

Batch Size、Iteration、Step、Epoch

Batch 是一次送进去计算的一批样本，batch size 是其中有多少样本。Iteration 通常指训练循环执行一次，但要看代码具体怎么定义。Optimizer step 是一次实际参数更新。Epoch 通常指完整遍历一次有限训练数据。

例如有一千条训练样本，每批一百条，不丢弃样本且每批更新一次，那么一轮会处理十批，也会更新十次。这不是十个 epoch，而是一个 epoch 里的十个更新步骤。语料持续流入或数据规模极大时，研究者也会直接报告训练 step 或处理的 token 数，而不是强调完整遍历了几遍。

Gradient Accumulation 与 Microbatch

显存放不下一大批样本时，可以分成多个 microbatch 分别前向、反向，累计梯度后再更新一次。例如每个小批结束都计算梯度，但四个小批后才更新参数，那么四次迭代只对应一次 optimizer step。它能帮助获得较大的有效批量，但并不总与一次性的大 batch 严格等价，BatchNorm 的批次统计等因素会造成差别。梯度累积也不表示模型参数在每个小批后已经改变。

Zero Grad、Detach、Stop Gradient

一些框架默认把新梯度累加到已有梯度上，所以需要在合适的更新边界清空它们。忘记清空可能把旧梯度反复算进去；需要累积时过早清空，又会破坏预期。Detach 或 stop gradient 表示切断某条路径上的梯度传播，常用于目标网络、教师分支或避免不必要的计算图。它通常不等于复制出完全独立的一份数据，也不等于冻结整个模型。

Train Mode、Eval Mode、No Grad

Train mode 和 eval mode 控制某些层的运行行为，例如 Dropout 和 BatchNorm。关闭梯度记录则是在决定是否建立反向计算所需的记录。两者不同：切换到 eval 并不自动等同于关闭所有梯度，关闭梯度也不会自动改变 Dropout 的训练行为。评价或部署时经常两方面都要正确设置，才能既稳定又节省资源。

Checkpoint、Resume 与 Seed

Checkpoint 保存训练状态。只保存模型权重通常足以用于推理；想较准确地恢复训练，还可能需要优化器状态、学习率调度进度、随机数状态和数据读取位置。Seed，随机种子，使随机初始化或数据打乱更可控，但不同硬件和非确定性计算仍可能导致差异。Reproducibility 是过程可复现，不只是记下一个随机种子。

Validation 与 Early Stopping

训练中定期在未用于该次拟合的验证数据上检查效果。训练误差下降而验证误差长期变差，是过拟合的一种常见信号。Early stopping 根据验证表现停止，并通常保留较好的模型检查点。Patience 是允许连续多少次检查没有改善，不一定是固定多少秒，也不一定是固定多少 epoch。测试集不应被反复拿来决定什么时候停，否则它失去独立评估价值。

梯度累积的尾批：十个小批为什么更新三次

假设一轮恰有十个等大小的小批，每四个小批累积后更新一次，并决定保留尾部数据。那么前四批更新一次，中间四批再更新一次，最后两批仍应更新一次，总计三次。若代码只在批次编号能被四整除时更新，又在下一轮开始清空梯度，最后两批就白算了。也可以有意丢弃或跨轮累积，但必须明确记录这个选择。

若希望每组更新使用该组样本的平均损失，前两组各按四个等大小小批平均，尾组应按两个平均。全程机械地除以四，会让尾组梯度变小。小批大小不等时，还应按实际样本数加权；语言模型中有效 token 数不等时，常应按有效 token 数处理。只有各设备和小批等大小、损失归一化一致时，才可以直接用小批大小乘累积次数乘数据并行设备数，估算有效批量。
