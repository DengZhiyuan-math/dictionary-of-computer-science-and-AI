第 50 讲。序列与图网络：RNN、LSTM、GRU、GCN、GAT、Mamba。

RNN 与 Hidden State

RNN 按序读取输入，用 hidden state，隐藏状态，压缩已经看到的历史，再结合下一个输入更新。它适合流式序列处理，但很长历史的信息可能被遗忘，训练也容易遇到梯度传播困难。隐藏状态不是对整个过去的无损存档。推理时通常可以持续更新状态，不必像普通全注意力那样保留所有过去位置的完整缓存。

LSTM 与 GRU

LSTM 使用门控来决定哪些信息写入、保留或输出，并引入专门的记忆路径，缓解长期依赖问题。GRU 用更精简的门控结构实现类似目的。门是由数据和可学习参数控制的软选择，不是人工在每个时刻决定开关。它们改善记忆能力，但不保证无限长序列都能可靠记住，也不因为 Transformer 流行就变成毫无用途。

Sequence-to-Sequence 与 Attention

Seq2seq 把一个序列变成另一个序列，如翻译。早期编码器把输入压成固定表示，解码器再生成输出；attention 允许生成某一步时直接关注相关输入位置，减轻全部信息挤进一个向量的压力。Self-attention 在同一序列内交互，cross-attention 在一组表示与另一组表示之间取信息。Encoder、decoder 描述角色，不限定必须使用 RNN。

Teacher Forcing 与 Exposure Bias

Teacher forcing 在训练生成模型时，用真实前文作为下一步输入，而不是总用模型自己刚刚生成的错误。这提高训练效率，却造成训练条件与自由生成时的条件不同。Exposure bias 指这种差异可能使早先错误不断影响后续。自回归语言模型常在一个训练序列中并行计算多个位置的预测损失，但生成新内容仍通常一步步进行。

GCN、GraphSAGE、GAT

图神经网络沿边交换并聚合邻居信息。GCN 用图结构规范化等方式混合邻居特征。GraphSAGE 采样邻居并学习聚合，适合大图或新节点场景。GAT 使用注意力为不同邻居赋予不同权重。它们适合分子、关系网络和推荐图。层数太多可能让不同节点表示变得相似，这叫 oversmoothing；结构本身不代表因果关系。

Equivariance 与 Message Passing

Message passing 是邻居之间传递信息的通用框架。Equivariance，等变性，指输入经过某种变换后，输出按相应方式变换，例如物体旋转后预测方向也相应旋转。它不同于 invariance，不变性，后者希望输出不变。分子与三维物理任务中，合理利用这类结构可以减少模型重复学习同一对称关系的负担。

State Space Model、S4、Mamba

神经状态空间序列模型用内部状态传播序列信息，提供与标准自注意力不同的路线。S4 利用结构化状态空间计算长程关系；Mamba 通过输入相关的选择机制决定信息如何保留与传播，并重视硬件高效实现。它们不是把经典卡尔曼滤波换个名字，也不保证在所有任务上胜过 attention。长序列效率、信息压缩与精确检索能力之间仍存在取舍。
