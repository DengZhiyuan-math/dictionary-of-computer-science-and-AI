第 27 讲。决策树与随机森林：从一次提问到许多不同的树。

Decision Tree、Node、Leaf、Split

决策树通过一系列条件把样本分组。Node 是节点，split 是划分，leaf 是不再继续划分的叶节点。预测新订单是否取消时，树可能先按价格区间分，再按配送时间分，最后在叶节点给出取消比例等预测。分类树预测类别或概率，回归树预测连续值。树不是人在训练前手写好的全部规则；训练会依据目标选择特征与切分点。

Gini、Entropy、Information Gain、CART

树希望划分后的组更容易预测。Gini impurity 和 entropy 是衡量分类混杂程度的常见标准，information gain 衡量划分改善了多少。回归树则常依据目标数值的误差减少来划分。CART 是分类与回归树的经典路线，通常采用二叉切分。听到信息增益，不必推导公式，只要知道它在衡量一次提问让样本变得更清楚了多少。

Max Depth、Min Samples Leaf 与 Pruning

最大深度控制最多连续问多少层。叶节点最小样本数避免为极少样本建立过于特殊的规则。剪枝删除收益不足的分支。单棵深树可以把训练数据切得非常细，却对新样本不稳定；训练数据轻微改变，树结构也可能明显变化。限制复杂度可以减轻这种问题，但过浅的树又可能无法表达真正关系。

Bootstrap 与 Bagging

Bootstrap 是从原训练样本中有放回抽样，因此某些样本会重复，另一些不会被抽到。Bagging 用不同抽样数据训练多个模型，再综合预测。它希望不同模型的偶然错误相互抵消。不是随便复制同一个模型多次就有效：如果所有模型总在同一处犯同样的错，平均结果也不会解决问题。多样性与每个模型本身的质量都很重要。

Random Forest，随机森林

随机森林用很多棵树共同预测。经典训练中，每棵树使用不同的 bootstrap 样本；每次选择划分时，还只考虑随机抽取的一部分候选特征。第二层随机性很关键：如果某个特别强的特征总在树顶出现，所有树容易长得相似，限制候选特征能让它们探索不同规则。

预测时，回归通常平均多棵树的数值；分类可以投票或平均类别概率，具体看实现。直觉是让一群有不同观察角度的判断者一起工作，降低单棵树的高方差。它不能消除大家共同缺少的信息，也不意味着完全不会过拟合。

N Estimators、Max Features、OOB

N estimators 通常是树的数量。增加树往往让集成结果更稳定，但训练、预测和存储成本也增加，收益会趋于饱和。Max features 控制划分时可看的候选特征多少，影响树的强度与相似性。OOB，袋外样本，是某棵树在有放回抽样时没有抽到的样本，可用对应未见过它的树作一种内部评估。但时间或分组依赖问题仍需专门验证，OOB 不是万能独立测试集。

Extra Trees 与局限

Extra Trees 在切分点选择上引入更强随机性，常能更快构建多样化的树，属于相关的随机树集成路线。随机森林与 Extra Trees 都适合表格数据上的非线性关系。普通树叶输出平均值的回归森林不擅长超出观察范围的外推。特征重要性也可能受相关性、取值数量和计算方式影响，不能把重要性排名直接称为因果贡献。

面试口述：随机森林在样本和每次分裂的候选特征上引入随机性，训练许多不太相似的树，再综合预测。它主要通过降低方差提高稳定性，常用于表格分类与回归；代价是模型体积、预测成本和有限的外推能力。
