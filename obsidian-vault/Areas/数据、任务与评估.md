# 数据、任务与评估

[[00-知识地图|知识地图]]

**核心问题：** 输入和目标是什么，怎样判断模型对新数据有效？

建立样本、标签、预测任务、数据划分、评价指标和因果边界，是模型比较与实验的共同基础。

## 概念入口

- [[Concepts/二分类／互斥多分类／多标签|二分类／互斥多分类／多标签]]：分别对应是非判断、多个互斥答案中选一个、多个答案可以同时成立。
- [[Concepts/广播|广播]]：按形状规则扩展较小张量的运算含义，避免手动复制。
- [[Concepts/概率校准|概率校准]]：检查报出的概率与长期实际发生比例是否相符。
- [[Concepts/交叉验证|交叉验证]]：用多次数据划分评价训练流程，必要时以嵌套方式隔离模型选择。
- [[Concepts/数据泄露|数据泄露]]：训练或选择模型时无意利用了实际预测拿不到的信息。
- [[Concepts/数据类型／计算设备|数据类型／计算设备]]：Dtype 指数值表示方式，Device 指数据与运算所在的 CPU 或 GPU 等设备。
- [[Concepts/精确率与召回率的调和平均|精确率与召回率的调和平均]]：用一个数汇总 Precision 与 Recall，偏低的一项会限制结果。
- [[Concepts/概率变换前的分数|概率变换前的分数]]：神经网络分类语境中，通常是尚未经过 Sigmoid 或 Softmax 的原始分数。
- [[Concepts/按类平均／汇总计数|按类平均／汇总计数]]：Macro 先算各类再等权平均；Micro 汇总计数后计算。
- [[Concepts/参数／超参数|参数／超参数]]：参数由拟合获得，超参数通常控制模型结构或训练方式。
- [[Concepts/精确率|精确率]]：预测为正的对象中，真正为正的比例。
- [[Concepts/召回率|召回率]]：真实正类中被找到的比例，也称敏感度或真阳性率。
- [[Concepts/排序区分指标|排序区分指标]]：ROC 汇总真阳性率与假阳性率；PR 汇总精确率与召回率的变化。
- [[Concepts/样本／特征／标签|样本／特征／标签]]：样本是一条学习对象，特征是可用输入，标签是监督答案。
- [[Concepts/S 形概率变换|S 形概率变换]]：把一个实数分数映射到零和一之间，常用于二元标签的概率。
- [[Concepts/类别概率归一化|类别概率归一化]]：把一组分数转为总和为一的类别概率。
- [[Concepts/张量／形状／轴|张量／形状／轴]]：张量组织多维数据；形状给出各轴大小；轴表示计算或排列的方向。
- [[Concepts/分类阈值|分类阈值]]：把概率或分数转成硬分类决策的边界。
- [[Concepts/特征处理与数据划分|特征处理与数据划分]]：把原始数据变成任务可用输入，在正确训练划分内估计处理统计。
- [[Concepts/因果、干预与不确定性|因果、干预与不确定性]]：区分相关预测与干预效应，利用实验、假设和不确定性评估支持结论。
