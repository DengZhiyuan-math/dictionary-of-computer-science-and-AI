# 数据结构与算法

[[00-知识地图|知识地图]]

**核心问题：** 怎样组织数据并减少计算与存储成本？

从数据结构、复杂度与算法设计思想，走到树、图、字符串、搜索和优化。

## 概念入口

- [[Concepts/广度／深度优先搜索|广度／深度优先搜索]]：BFS 逐层扩展，DFS 沿路径深入后回退。
- [[Concepts/非负权最短路算法|非负权最短路算法]]：反复确定当前最近节点，并用它松弛其他路径。
- [[Concepts/动态规划|动态规划]]：保存可复用的子问题结果，按状态与转移关系求解。
- [[Concepts/哈希表|哈希表]]：把键映射到存储位置，以支持高效的按键查找。
- [[Concepts/贪心与安全选择|贪心与安全选择]]：通过可证明安全的当前选择或边界扩展，逐步构造满足目标的解。
- [[Concepts/复杂度与资源成本|复杂度与资源成本]]：把时间、辅助空间与输出成本分开分析，并说明期望、摊还和最坏情况的差别。
- [[Concepts/递归与子问题契约|递归与子问题契约]]：定义一个调用解决什么子问题、返回什么结果，以及何时终止，再组织子调用。
- [[Concepts/数组、链表、树与图|数组、链表、树与图]]：根据主要操作选择信息的组织方式，理解访问、更新、顺序与连接关系的成本。
- [[Concepts/图、路径与依赖|图、路径与依赖]]：把连接、可达、最短路与先后依赖转成节点、边及相应遍历或优化问题。
- [[Concepts/并查集|并查集]]：用代表元维护互不重叠集合，支持连通判断与合并。
- [[Concepts/零一最短路|零一最短路]]：用双端队列处理边权只有 0 与 1 的最短路。
- [[Concepts/Bellman-Ford 与负环|Bellman-Ford 与负环]]：重复松弛处理负边，并区分源点可达负环的影响。
- [[Concepts/树状数组|树状数组]]：以二进制分块支持单点加与前缀求和。
- [[Concepts/线段树与懒标记|线段树与懒标记]]：分层维护可合并的区间摘要，并按需传播区间更新。
- [[Concepts/差分数组|差分数组]]：用区间端点变化压缩批量区间加，最后以前缀累加还原。
- [[Concepts/KMP 与前缀函数|KMP 与前缀函数]]：利用已匹配部分的真前后缀在失配后复用比较信息。
- [[Concepts/多模式自动机|多模式自动机]]：在前缀树上使用失败链接与输出关系寻找多个模式。
- [[Concepts/最长递增子序列与结尾状态|最长递增子序列与结尾状态]]：保存每种长度的最小结尾，以二分更新最长严格递增长度。
- [[Concepts/带权区间调度|带权区间调度]]：按结束时间组织任务，把选择接到兼容前驱的最优收益。
- [[Concepts/区间动态规划|区间动态规划]]：用连续区间定义子问题，枚举切分并按长度填表。
- [[Concepts/状态压缩动态规划|状态压缩动态规划]]：把小规模集合编码进状态，显式保留访问集合与终点。
- [[Concepts/二分答案与可行性|二分答案与可行性]]：利用候选答案下的单调可行性查找最优边界。
- [[Concepts/蓄水池采样|蓄水池采样]]：在未知长度的数据流中使用固定空间进行均匀采样。
- [[Concepts/布隆过滤器|布隆过滤器]]：用位数组与多个哈希位置做允许假阳性的成员过滤。
- [[Concepts/摊还分析|摊还分析]]：通过一串操作的总代价说明每次操作的平均分摊成本。
