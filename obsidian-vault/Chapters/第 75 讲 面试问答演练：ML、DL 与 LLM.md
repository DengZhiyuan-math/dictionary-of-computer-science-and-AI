## 第 75 讲｜面试问答演练：ML、DL 与 LLM

领域：口述练习 · 导览 / 复习

<a id="chapter-75-section-01"></a>

### 问题十六：机器学习主要有哪些类型？

【答题停顿】参考回答：监督学习根据标签预测结果，包括分类和回归。无监督学习寻找数据结构，例如聚类和降维。自监督学习从数据本身构造训练任务。强化学习通过与环境交互优化长期奖励。

<a id="chapter-75-section-02"></a>

### 问题十七：你知道哪些经典机器学习算法？

【答题停顿】参考回答：我熟悉线性回归、逻辑回归、决策树、随机森林、Gradient Boosting、XGBoost、SVM、KNN、K-means、PCA，以及神经网络的基本思想。具体选择取决于目标类型、数据规模、数据结构和可解释性要求。

<a id="chapter-75-section-03"></a>

### 问题十八：什么是随机森林？

【答题停顿】参考回答：它训练许多带随机性的决策树，通常同时在样本和节点特征选择上引入随机性，再综合预测。这样可以降低单棵决策树的高方差，常用于表格分类与回归。

<a id="chapter-75-section-04"></a>

### 问题十九：随机森林和 XGBoost 有什么区别？

【答题停顿】参考回答：随机森林强调训练多个多样化的树，再综合结果，主要降低方差。XGBoost 属于 Gradient Boosting，逐步添加新树来优化整体目标。两者都是强大的表格数据方法，但训练方式不同。

<a id="chapter-75-section-05"></a>

### 问题二十：逻辑回归为什么可以做分类？

【答题停顿】参考回答：它把输入特征的加权组合转换成类别概率，再通过阈值作出分类判断。优点是简单、可解释，常用作二分类基线。

<a id="chapter-75-section-06"></a>

### 问题二十一：K-means 是做什么的？

【答题停顿】参考回答：它是无监督聚类算法。先设定分组数量，再交替把样本分给附近的簇中心、更新中心。适合发现距离意义下比较紧凑的群组，但结果依赖簇数量和距离度量。

<a id="chapter-75-section-07"></a>

### 问题二十二：什么是过拟合？

【答题停顿】参考回答：模型对训练数据中的特殊细节学得太多，训练表现很好，但对没见过的数据预测变差。可以通过合理划分数据、正则化、控制复杂度和提前停止等方法缓解。

<a id="chapter-75-section-08"></a>

### 问题二十三：准确率高是不是模型就好？

【答题停顿】参考回答：不一定。如果欺诈交易只有很小比例，全部预测正常也会获得很高准确率。要根据任务代价关注 Precision、Recall、F1、PR AUC，以及概率校准和业务指标。

<a id="chapter-75-section-09"></a>

### 问题二十四：什么是数据泄露？

【答题停顿】参考回答：训练或验证过程中无意使用了预测时根本拿不到的信息，导致离线成绩过高。时间序列尤其容易出现未来数据泄露。

<a id="chapter-75-section-10"></a>

### 问题二十五：什么是反向传播？

【答题停顿】参考回答：反向传播利用链式法则，高效计算网络各层参数对最终损失的影响，再配合梯度下降或 Adam 这样的优化器来更新参数。

<a id="chapter-75-section-11"></a>

### 问题二十六：CNN 和 Transformer 有什么不同？

【答题停顿】参考回答：CNN 利用局部卷积和权重共享，天然适合图像的局部结构。Transformer 主要利用注意力机制，让序列不同位置动态交换信息。它们也可以混合使用。

<a id="chapter-75-section-12"></a>

### 问题二十七：什么是 Attention？

【答题停顿】参考回答：注意力允许模型根据当前上下文，有选择地从其他位置提取信息。自注意力在同一序列内部建立关系，是 Transformer 的核心设计之一。

<a id="chapter-75-section-13"></a>

### 问题二十八：大语言模型本质上在做什么？

【答题停顿】参考回答：典型自回归语言模型根据已有上下文预测下一个 Token。通过大规模预训练，它逐渐学习语言和数据中的复杂结构，再通过后训练改善指令遵循和任务能力。

<a id="chapter-75-section-14"></a>

### 问题二十九：预训练和微调有什么区别？

【答题停顿】参考回答：预训练用大规模数据学习一般性结构。微调是在已有模型基础上继续训练，使其更适合特定任务、领域或回答风格。微调不必更新全部模型参数。

<a id="chapter-75-section-15"></a>

### 问题三十：SFT、RLHF、DPO 是什么？

【答题停顿】参考回答：SFT 用示范答案进行监督微调。RLHF 利用人类偏好信号进行强化学习。DPO 通过偏好数据直接优化模型，是偏好优化的另一条路线，通常不需要经典 RLHF 中单独的奖励模型训练步骤。

<a id="chapter-75-section-16"></a>

### 问题三十一：什么是 MoE？

【答题停顿】参考回答：混合专家模型在某些层设置多个专家网络，再由路由机制针对输入激活部分专家。目的之一是扩大总参数容量，同时控制每次计算激活的参数量。

<a id="chapter-75-section-17"></a>

### 问题三十二：什么是 KV Cache？

【答题停顿】参考回答：在模型逐 Token 生成时，保存前面 Token 已计算过的注意力 Key 和 Value，避免每一步重复计算全部历史上下文。它能加速解码，但消耗显存。

<a id="chapter-75-section-18"></a>

### 问题三十三：如何降低 LLM 推理成本？

【答题停顿】参考回答：可以考虑模型选型、减少无效上下文、量化、批处理、KV Cache 管理和推测解码。具体优化要先确定瓶颈在计算、显存、内存带宽还是请求调度。

<a id="chapter-75-section-19"></a>

### 问题三十四：模型幻觉是怎么回事？

【答题停顿】参考回答：模型可能生成语言上流畅却缺乏事实依据的内容。成因与训练目标、知识缺口和上下文约束有关。可以通过检索、工具核验、结构化输出和评测降低风险，但无法保证彻底消除。

<a id="chapter-75-section-20"></a>

### 问题三十五：什么是 RAG？

【答题停顿】参考回答：它是检索增强生成。先从外部数据源找相关资料，再把这些资料交给语言模型生成回答，适合企业知识库、动态文档和需要证据的问答。它不会自动保证检索质量或最终答案正确。
