## 第 77 讲｜训练微知识点：二十道口述追问

领域：口述练习 · 细讲

每道题先尝试自己回答，再听参考回答。这里考的是概念与边界，不要求背公式或实现。

<a id="chapter-77-section-01"></a>

### 问题 1：BCE 是什么，为什么不用准确率直接训练？

【答题停顿】

参考回答：BCE 是二元交叉熵，用来评价二元概率预测。它区分“只是判断错了”和“非常自信地判断错了”，为训练提供更细的反馈。准确率只看过阈值后的对错，对参数的小变化往往没有连续反馈。

<a id="chapter-77-section-02"></a>

### 问题 2：BCE 与 Cross-Entropy 是互相排斥的两种概念吗？

【答题停顿】

参考回答：不是。BCE 本身是二元情形下的交叉熵。日常代码中的 CrossEntropyLoss 常用于互斥多类别，而 BCE 常用于二分类或逐标签的多标签任务。要看标签关系，不能只看类别数量。

<a id="chapter-77-section-03"></a>

### 问题 3：BCEWithLogitsLoss 的名字说明什么？

【答题停顿】

参考回答：它直接接收概率变换之前的原始分数，并把 Sigmoid 与 BCE 合在内部计算，改善数值稳定性。一般不应先在外面再做一次 Sigmoid。

<a id="chapter-77-section-04"></a>

### 问题 4：Logit 与 Probability 有什么区别？

【答题停顿】

参考回答：Logit 是分类模型的原始分数，可为负或大于一。通过 Sigmoid 或 Softmax 等转换才得到概率形式。概率看起来规范，也不代表已经校准可靠。

<a id="chapter-77-section-05"></a>

### 问题 5：一张图可以同时有猫和狗，应该怎样理解任务？

【答题停顿】

参考回答：这是多标签任务。可以分别估计有没有猫、有没有狗，不要求这些概率加起来为一。若规定每张图只能属于猫、狗、鸟中的一种，才是互斥多类别单标签任务。

<a id="chapter-77-section-06"></a>

### 问题 6：Learning rate 是训练快慢的直接计时器吗？

【答题停顿】

参考回答：不是。它控制参数更新的总体步幅。太大可能不稳定，太小可能在预算内改善缓慢，但实际训练耗时还由硬件、模型、数据和批量等决定。

<a id="chapter-77-section-07"></a>

### 问题 7：Warmup 与 Warm start 有什么区别？

【答题停顿】

参考回答：Warmup 是训练开始时逐步提高学习率，使起步更平稳。Warm start 通常指从已有模型或状态继续训练，而不是重新随机初始化。

<a id="chapter-77-section-08"></a>

### 问题 8：Batch、Step、Epoch 分别是什么？

【答题停顿】

参考回答：Batch 是一批输入样本。Optimizer step 是一次参数更新。Epoch 通常是遍历一次训练数据。使用梯度累积时，多个 batch 才对应一次更新，不能把三者混为一谈。

<a id="chapter-77-section-09"></a>

### 问题 9：反向传播会自动完成参数更新吗？

【答题停顿】

参考回答：反向传播主要计算梯度，优化器才根据梯度及历史状态更新参数。实际代码可能把流程封装起来，但概念上仍是不同环节。

<a id="chapter-77-section-10"></a>

### 问题 10：梯度累积为什么能帮助训练？

【答题停顿】

参考回答：显存放不下大 batch 时，可以分多个小批计算并累计梯度，之后更新一次，获得较大的有效批量。它不一定与一次性大 batch 严格等价，例如 BatchNorm 的批次统计可能不同。

<a id="chapter-77-section-11"></a>

### 问题 11：SGD、Momentum、Adam 大致怎样区分？

【答题停顿】

参考回答：SGD 根据抽样梯度更新，Momentum 还累积历史方向，Adam 再结合逐参数梯度尺度的历史统计。它们是优化器设计，不是三种不同神经网络。

<a id="chapter-77-section-12"></a>

### 问题 12：AdamW 比 Adam 主要多了什么思想？

【答题停顿】

参考回答：AdamW 把权重衰减与 Adam 的自适应梯度处理解耦。不能把自适应优化器里的 L2 惩罚简单等同于这种衰减。它仍需要合适学习率与验证。

<a id="chapter-77-section-13"></a>

### 问题 13：学习率衰减与权重衰减是不是同一件事？

【答题停顿】

参考回答：不是。学习率衰减改变之后更新的步幅。权重衰减对权重施加收缩倾向，是一种控制模型参数的机制。两者可以同时使用。

<a id="chapter-77-section-14"></a>

### 问题 14：Dropout 是永久删除一部分神经元吗？

【答题停顿】

参考回答：不是。它通常在训练时随机屏蔽部分激活，减少过度依赖特定通路；推理时一般使用对应的完整网络与尺度处理。永久删结构更接近剪枝。

<a id="chapter-77-section-15"></a>

### 问题 15：BatchNorm 与 LayerNorm 为什么不同？

【答题停顿】

参考回答：BatchNorm 使用批次相关统计，LayerNorm 通常在单个样本或 token 的特征维度处理。它们依赖的统计范围不同，因此小批量、序列和评估模式下的行为也不同。

<a id="chapter-77-section-16"></a>

### 问题 16：Eval mode 与 No grad 可以互相替代吗？

【答题停顿】

参考回答：不可以。Eval mode 改变 Dropout、BatchNorm 等层的行为，No grad 关闭梯度记录。正确评估或部署时常需要两方面都设置合适。

<a id="chapter-77-section-17"></a>

### 问题 17：Focal Loss 与 Class weight 是同一个技巧吗？

【答题停顿】

参考回答：不是。类别权重按标签类别改变贡献，Focal Loss 根据当前样本是否容易预测动态减少容易样本的贡献。它可能关注难例，也可能过度关注错误标签。

<a id="chapter-77-section-18"></a>

### 问题 18：MSE、MAE、Huber 怎么选择？

【答题停顿】

参考回答：MSE 更强调大的误差，MAE 对极端误差相对稳健，Huber 在小误差与大误差区域采用折中处理。选择取决于误差成本、异常值和优化需求，不是哪个名字更先进。

<a id="chapter-77-section-19"></a>

### 问题 19：模型 AUC 很高，概率就可信吗？

【答题停顿】

参考回答：不一定。AUC 主要评价排序区分，概率校准关注报出的百分比是否与实际发生比例一致。一个模型可以排序很好，却系统性地过分自信。

<a id="chapter-77-section-20"></a>

### 问题 20：训练出现 NaN 与 OOM 应该怎样区分？

【答题停顿】

参考回答：NaN 是无效数值，可能来自不稳定运算、极端梯度或错误数据。OOM 是内存不足，应检查批量、序列长度、模型和激活存储。它们不是同一种错误。
