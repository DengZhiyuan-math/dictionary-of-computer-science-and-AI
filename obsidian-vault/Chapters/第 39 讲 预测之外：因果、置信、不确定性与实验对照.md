## 第 39 讲｜预测之外：因果、置信、不确定性与实验对照

领域：机器学习算法 · 细讲

<a id="chapter-39-section-01"></a>

### Prediction 与 Causal Effect【重点】

预测问题问看到这些特征时结果可能怎样。因果问题问主动改变某个因素会怎样。用户收到优惠券后购买率高，不代表优惠券造成全部差异，因为营销系统可能本来就给高意愿用户发券。混杂变量同时影响是否收到处理和结果，造成表面关联。高预测准确率不能替代因果识别。

<a id="chapter-39-section-02"></a>

### A/B Test 与 Randomization【重点】

A/B 测试随机分配处理，以减少已知和未知混杂的系统性差别。仍需考虑实验单位、用户互相影响、样本量、指标定义和提前停试等问题。统计显著不等于业务收益足够大，不显著也不直接证明两种方法相同。这里不是要求推导检验，而是知道实验设计决定证据能说明什么。

<a id="chapter-39-section-03"></a>

### Propensity Score、Matching、IPW【认识】

观察数据中，倾向得分估计一个对象得到某种处理的可能性。Matching 找可比较对象，IPW 通过重新加权构造更可比的群体。它们依赖重要假设，例如关键混杂已被测量、不同对象有机会接受不同处理。机器学习把倾向得分预测得很准，也不能弥补根本不存在的可比样本。

<a id="chapter-39-section-04"></a>

### Doubly Robust、Causal Forest、Uplift【认识】

双重稳健方法组合处理分配模型和结果模型，在适当条件下允许其中一部分模型误设而仍有稳健性质。Causal forest 寻找不同人群的处理效果差异。Uplift 建模关注干预带来的增量，而不是谁本来就最可能购买。把优惠券发给最可能购买的人，与发给最容易被优惠券改变行为的人，是不同目标。

<a id="chapter-39-section-05"></a>

### Aleatoric 与 Epistemic Uncertainty【重点】

Aleatoric uncertainty 来自观察噪声或现象本身的随机性。Epistemic uncertainty 来自模型知识不足，更多相关数据可能减少它。输出一个概率不是已经把所有不确定性说明清楚；预测分布很集中也可能只是模型过度自信。深度集成或贝叶斯方法可提供相关估计，但仍需校准与分布外检查。

<a id="chapter-39-section-06"></a>

### Bootstrap 与 Conformal Prediction【认识】

Bootstrap 重采样评估某些统计量的变动，但必须尊重数据依赖，不能对时序盲目逐点重抽。Conformal prediction 使用校准误差构造预测区间或集合，在交换性等适当条件下可获得覆盖保证。标准保证通常是总体边际意义，不是每个个体条件下都精确覆盖，也不自动适用于任意分布漂移。

<a id="chapter-39-section-07"></a>

### Baseline、Control、Ablation、Sensitivity Analysis【重点】

Baseline 是简单参考，control 是实验对照，ablation 是移除组件看贡献，sensitivity analysis 是改变合理假设或设置看结论是否稳定。它们都是避免被一个漂亮结果说服的工具。你不必在通识阶段掌握所有因果算法，但应能明确说：模型相关性、实验差异和干预效果是不同种类的结论。
