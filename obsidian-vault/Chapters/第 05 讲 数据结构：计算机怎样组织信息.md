## 第 05 讲｜数据结构：计算机怎样组织信息

领域：算法与数据结构 · 导览 / 复习

数据结构可以理解为数据的收纳方式。不同收纳方式，决定了查找、插入、删除和排序的成本。

Array，数组，把元素按顺序放在可索引的位置，适合快速按位置访问。Dynamic Array，动态数组，可以扩容；Python 的 list 大致属于这一类。Linked List，链表，通过指针连接节点，适合某些位置上的插入与删除，但不擅长随机访问。Stack，栈，后进先出，就像叠盘子；常见于函数调用、撤销操作。Queue，队列，先进先出，像排队取号；常见于任务调度。Deque，双端队列，允许两端进出。

Hash Table，哈希表，是必须理解的重点。它用哈希函数把一个键映射到某个存储位置，以便快速查找。Python 的字典和集合就采用哈希相关的思想。它的平均查找通常很快，但哈希冲突、内存成本和最坏情况仍然存在。Hash Map 保存键和值；Hash Set 主要用于判断元素是否存在。

Tree，树，是层次化结构。Binary Tree，二叉树，每个节点最多两个子节点。Binary Search Tree，二叉搜索树，用有序关系支持搜索。AVL Tree 和 Red-Black Tree，平衡二叉搜索树，避免树退化得太深。Heap，堆，是另一种树形结构，它并不是把所有元素都完全排序，而是让最大或最小元素容易取出。Priority Queue，优先队列，经常由堆实现，用于调度最紧急的任务。

Trie，字典树，根据字符前缀组织词汇，适合自动补全和前缀检索。B Tree 和 B Plus Tree 是数据库中常见的磁盘友好型索引结构，能够减少大规模数据检索时的磁盘访问。Graph，图，用节点和边表达关系，社交网络、地图和依赖关系都可以看成图。Adjacency List 和 Adjacency Matrix 分别是邻接表和邻接矩阵，是保存图的两类方法。

Union Find，也叫并查集，用于高效判断两个元素是否属于同一连通集合，常见于网络连通性和聚类相关问题。Bloom Filter，布隆过滤器，用很小的空间快速判断某个元素可能存在或一定不存在；它允许假阳性，但在标准设置下不会产生假阴性。适合大型系统提前过滤无效查询。

现代 AI 还常用向量索引。Embedding 把文字、图像或其他对象表示为向量。近似最近邻搜索，ANN，不保证永远找到精确最近的对象，但速度更快。HNSW 是常见的基于多层图结构的近似向量搜索方法，在语义检索中经常出现。

本讲记住：数组强调顺序访问，哈希表强调按键查找，树强调有序或层次结构，堆强调优先级，图强调关系，向量索引强调相似度搜索。
