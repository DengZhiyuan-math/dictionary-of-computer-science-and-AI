# Postorder DP · 树上动态规划的返回值与全局答案

概念编号：`concept:postorder-dp` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/postorder-dp/)

## 第一层：概念入门 · 知其然

### 定义

后序树形动态规划先解决一个节点的子树，再汇总为该节点的子树答案。树是无环的层次连接结构，指定根后，每个非根节点有唯一父节点；后序保证孩子先于父节点。状态必须说明答案是否包含根、能否与父亲连接等边界，才能合法组合互不重叠的子树。

### 概念边界与常见混淆

一般有环图不能直接按树的独立子树合并。深树递归也可能超出调用栈，迭代后序是实现选择，状态逻辑并不因此改变。

### 先看一个例子

每节点有收益，选若干节点且相邻不可同选。根收益5，两个叶子各收益4。若选根，只能得5；若不选根，两叶可同选得8。保存“选本节点”与“不选本节点”两个值，再供父亲选择；只保存一个最大8会丢失是否与父亲冲突的信息。

### 理解练习

#### 1. 状态

父亲已选，孩子能直接贡献它的全部最大值吗？

<details><summary>答案与解释</summary>

不能，孩子必须不选，需读取对应状态而不是无约束最大值。

</details>

#### 2. 顺序

父节点在孩子前计算，已有足够信息吗？

<details><summary>答案与解释</summary>

通常不够，它依赖孩子结果，应先处理孩子或以等价依赖机制延期。

</details>

#### 3. 结构

两个子树共享同一后代，还能当独立树合并吗？

<details><summary>答案与解释</summary>

不能，可能重复计数或产生冲突；原树结构假设已被破坏。

</details>

### 原有解释与进一步例题


### 定义与应用范围

后序树形动态规划先求子树摘要，再合成当前节点的结果。它把动态规划用于树结构；递归只负责遍历顺序，状态的含义和能否向父节点延伸仍须单独定义。树高、直径、最大路径和可以采用相近遍历，却不能混用返回值。


### 参数、公式与边界

以节点数定义高度，空树 h=0，节点高度为 \(h(u)=1+\max(h_l,h_r)\)。若直径按边数计，经过当前节点的候选为 h_l+h_r。最大路径和中，返回父节点的增益只能选一侧；更新全局答案时才允许左右两侧同时接入。每个节点处理一次，时间为 O(n)，递归栈空间取决于树高。


### 例子

根节点的左右孩子都为叶子，左右高度均为 1，根高度为 2，直径是 2 条边。若计算最大路径和且整棵树只有值 −3 的节点，答案应是 −3；把全局答案初始化为 0 会错误地选择一条题目未允许的空路径。


### 适用边界与常见误解

A one-sided path passed upward differs from a candidate joining both sides at the current node.
