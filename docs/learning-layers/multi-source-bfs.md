# Multi-source BFS · 等时传播与最近源距离

概念编号：`concept:multi-source-bfs` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/multi-source-bfs/)

## 第一层：概念入门 · 知其然

### 定义

多源BFS在无权或统一边权图中，同时从多个起点扩展，计算每个节点从任一起点出发可达的最小边数。对无向图，这也就是该位置到最近起点的距离。把全部起点距离设为0并一同入队，再按普通广度优先逐层扩展；一个位置最先被哪一层发现，就得到最小距离。它求最近源距离，不是各起点距离的总和或平均；有向图必须保留所声明的方向。

### 概念边界与常见混淆

有向图若想求“到起点集合”的距离，应考虑反向边；从源出发求的是“源能到你”。权重不同时普通BFS层数不等于最小代价。

### 先看一个例子

五个位置排成0—1—2—3—4，两端0、4都是消防站。同步扩展得到距离[0,1,2,1,0]。若只从0出发，会得到[0,1,2,3,4]，无法回答离最近消防站多远。

### 理解练习

#### 1. 最近

位置1到两站距离1和3，输出应为2吗？

<details><summary>答案与解释</summary>

不是，应取最小1；平均2是另一个任务。

</details>

#### 2. 同步

先跑完第一个源才加入第二个，首次访问就固定距离可靠吗？

<details><summary>答案与解释</summary>

不可靠，第二个可能更近；应同步初始化或允许重新改善，不能沿用同一证明。

</details>

#### 3. 不可达

被墙隔开的区域没有任何站可达，距离应为0吗？

<details><summary>答案与解释</summary>

不应，0只给站点本身，应保留不可达标记。

</details>

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 从条件一步步推导

1. BFS按层推进，任一起点首次到达的距离就是所有起点中的最小值。
2. 统一访问标记避免重复扩散，队列工作仍为O(V+E)。

### 具体输入与计算步骤

一条线的5个格子0至4，起点为0和4。

1. 初始化距离[0,∞,∞,∞,0]，第一层使1与3为1。
2. 第二层使2为2，结果[0,1,2,1,0]。

计算结果：第二层使2为2，结果[0,1,2,1,0]。

地图上查询最近医院的步行格数。

1. 所有医院格子入队为0，墙壁不参与扩散。
2. 一次计算后每个可达格子都能直接读取最近医院距离。

应用结论：一次计算后每个可达格子都能直接读取最近医院距离。

### 原有解释与进一步例题


### 定义与应用范围

多源 BFS 把多个起点同时置为距离零，再按普通 BFS 扩展。它求等权图中每个可达节点到最近起点的最短距离，适合同时发生的传播或多个服务点的最近距离；不是从每个源分别重复整次搜索。


### 参数、公式与边界

对起点集合 S，\(d(v)=\min_{s\in S}\operatorname{dist}(s,v)\)。先把 S 中所有节点入队，并在首次入队时标记已发现，再向未发现邻居赋 d+1。邻接表实现的时间为 O(V+E)，辅助存储为 O(V)。若边耗时不同，层数不能直接当经过时间。


### 例子

一条五格通道的两端同时开始传播，初始队列含位置 0 和 4，距离依次为 (0,1,2,1,0)。只先完成左端的 BFS 再处理右端，会破坏“所有源同时开始”的初始化含义。若某格被障碍完全隔离，应保留不可达状态，不能把它当作零分钟到达。


### 适用边界与常见误解

With unequal edge travel times, layer count need not equal shortest travel time.
