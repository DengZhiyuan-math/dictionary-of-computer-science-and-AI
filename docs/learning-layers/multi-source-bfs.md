# Multi-source BFS · 等时传播与最近源距离

概念编号：`concept:multi-source-bfs` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/multi-source-bfs/)

## 第一层：概念入门 · 知其然

### 它是什么

多源 BFS 把多个起点同时置为距离零，再按普通 BFS 扩展。它求等权图中每个可达节点到最近起点的最短距离，适合同时发生的传播或多个服务点的最近距离；不是从每个源分别重复整次搜索。

### 先看一个例子

若某格被障碍完全隔离，应保留不可达状态，不能把它当作零分钟到达。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数、公式与边界

对起点集合 S，\(d(v)=\min_{s\in S}\operatorname{dist}(s,v)\)。先把 S 中所有节点入队，并在首次入队时标记已发现，再向未发现邻居赋 d+1。邻接表实现的时间为 O(V+E)，辅助存储为 O(V)。若边耗时不同，层数不能直接当经过时间。


### 例子

一条五格通道的两端同时开始传播，初始队列含位置 0 和 4，距离依次为 (0,1,2,1,0)。只先完成左端的 BFS 再处理右端，会破坏“所有源同时开始”的初始化含义。若某格被障碍完全隔离，应保留不可达状态，不能把它当作零分钟到达。


### 适用边界与常见误解

With unequal edge travel times, layer count need not equal shortest travel time.
