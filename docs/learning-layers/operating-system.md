# Operating System

概念编号：`concept:operating-system` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/operating-system/)

## 第一层：概念入门 · 知其然

### 它是什么

操作系统是管理处理器、内存和设备，并为程序提供受控使用方式的软件。进程是程序运行时的资源与隔离边界，线程是其中的执行单元。

### 先看一个例子

电脑同时播放音乐和编辑文档，操作系统安排它们获得处理器时间和内存。就像管理员安排多个住户使用公共设施，而不是让每个住户直接改动整栋楼的管线。

### 理解练习

两个程序都使用地址 0x1000，是否一定在读写同一块物理内存？

<details><summary>答案与解释</summary>

不是。进程通常有各自的虚拟地址空间，相同虚拟地址可以映射到不同物理内存；共享内存需要另外建立安排。

</details>

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 定义

操作系统管理进程、线程、内存与设备，并向应用提供受控接口。进程提供资源与隔离边界，线程是进程内部的执行单元；锁和死锁属于并发机制，不能代替操作系统本身的定义。


### 参数与公式

虚拟地址由进程地址空间映射，系统调用进入内核完成受保护的操作。调度器分配执行机会，文件描述符等句柄引用系统资源。并发表示任务时间区间重叠，是否同时在不同核心执行还取决于硬件与调度。


### 例子

两个进程各自使用虚拟地址 0x1000，可以映射到不同物理内存。一个进程的两个线程通常共享地址空间，同时更新共享计数可能发生竞争；需要按并发契约同步，不能因地址相同就把跨进程和进程内共享混为一谈。


### 适用边界与常见误解

Concurrency and parallelism describe task progress and execution; blocking and asynchrony describe waiting and control flow.
