# Neural Network

概念编号：`concept:neural-network` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/neural-network/)

## 第一层：概念入门 · 知其然

### 定义

神经网络是一类由可调参数控制、把输入转换为输出的计算模型。常见的前馈网络依次连接若干层：每层把上层数值按权重组合、加上偏置，再施加激活函数。权重和偏置是在训练中调整的数值；激活函数是预先选择的变换规则。训练通过比较预测与目标的差异来调整参数，并不赋予网络人的理解能力。

### 概念边界与常见混淆

如果各层都只有仿射变换而没有非线性，合成后仍是一个仿射变换，增加层数不会自动产生更丰富的函数形状。表达某函数的可能性，也不同于有限数据下能否学到并泛化。

### 先看一个例子

输入一个实数 x，隐藏层产生两个值：把 x 与 0 比较取大者，把 −x 与 0 比较取大者；输出把它们相加。因此输入 3 得 3，输入 −3 也得 3，整体实现绝对值。这里取大者的操作是非线性激活，两个分支负责正、负两侧；此例参数是人工指定的，并非声称训练一定会学到它们。

### 理解练习

#### 1. 参数与规则

绝对值例子中的权重与“取大者”规则，在通常训练中都由数据自由学习吗？

<details><summary>答案与解释</summary>

不是。通常权重、偏置被调整，而激活函数类型由模型设计指定；也有学习激活的扩展，但不能当作所有网络的定义。

</details>

#### 2. 只有线性组合

一层做 y=2x+1，下一层做 z=3y−2，是否因为两层就能表示绝对值？

<details><summary>答案与解释</summary>

不能。代入得 z=6x+1，仍是一条直线，不能同时形成绝对值两侧不同斜率。

</details>

#### 3. 表达与学习

网络能表达绝对值，是否保证只用正数训练后在负数上也正确？

<details><summary>答案与解释</summary>

不保证。许多函数在已见正数上相同、在负数上不同；训练信息及模型约束必须足以支持这种推广。

</details>

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 从条件一步步推导

1. 一层算z=Wx+b，再经非线性f得到输出。
2. 损失经链式法则反传得到参数梯度，再按优化器更新；多层纯线性仍等于单层线性。

### 具体输入与计算步骤

单神经元y=ReLU(wx+b)，x=2、w=1、b=−1，目标3，损失0.5(y−3)²。

1. z=1、y=1，损失2，梯度dw=(1−3)×2=−4。
2. 固定b，学习率0.1使w变1.4，新y=1.8。

计算结果：新损失0.5×1.2²=0.72，单步改善。

### 换到实际问题中应用

做图片分类模型。

1. 将输出转成类别分数，训练集优化交叉熵。
2. 用独立验证集选模型，测试集只评价最终泛化。

应用结论：训练误差低不证明能识别新图片。

### 举一反三：改变条件后的完整解答

若z为负且用ReLU，局部梯度如何？

<details><summary>变式的推演与答案</summary>

1. ReLU输出0，负半轴导数0。
2. 该样本对w的梯度为0。

可能出现停滞，应检查初始化、学习率或激活选择。

</details>

### 原有解释与进一步例题


### 定义

神经网络用多层带参数的变换把输入映射为输出，通过训练目标调整权重。非线性激活让多层网络可以表示超过单一线性模型的关系；层数更多不保证预测更准确。


### 参数与公式

一层可写为 $h=\phi(Wx+b)$，输出为 $\hat y=Uh+c$。x 为输入向量，W、U 为权重矩阵，b、c 为偏置，φ 为逐元素激活。训练最小化样本损失 L，并由反向传播计算参数梯度；网络输出的单位取决于任务。


### 例子

单个隐单元 h=max(0,2x−1)，输出 ŷ=3h+0.5。x=2 时 h=3、ŷ=9.5；若真实值为 10，平方误差为 0.25。用于深度对冲时，输出可以改为持仓数量，损失也应改为包含负债与成本的终端目标。


### 适用边界与常见误解

Network structure, loss function, optimization method and evaluation criteria are at different levels.
