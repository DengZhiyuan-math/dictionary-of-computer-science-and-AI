# Bootstrap / OOB

概念编号：`concept:bootstrap-oob` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/bootstrap-oob/)

## 第一层：概念入门 · 知其然

### 定义

自助法从观察到的数据中有放回抽样，用重复生成的样本近似研究估计量的波动。“有放回”指同一条记录可能被抽中多次，也可能一次未中。在袋装模型中，每个成员常用一份这样的样本训练；相对某个成员未被抽中的原始记录称为该成员的袋外样本，可用于检查该成员未直接训练过的数据表现。

### 概念边界与常见混淆

普通逐条自助抽样适用于相应独立同分布近似；有时间或群组依赖时要设计对应重采样单位。袋外评估也不能替代无限次模型选择后的独立测试。

### 先看一个例子

原始记录编号 [A,B,C,D]，抽四次得到 [A,A,C,D]。A 被重复使用，B 是这次的袋外记录；另一次抽样的袋外集合可能不同。随机森林的袋外预测可对 B 汇总所有没有用 B 训练的树，而不是使用所有树。B 可能参加过其他树的训练，不影响它对这棵树是袋外。

### 理解练习

#### 1. 放回抽样

抽四次是否保证四条原始记录都出现一次？

<details><summary>答案与解释</summary>

不保证。有放回允许重复，示例中 A 出现两次、B 未出现；这与随机打乱四条记录不同。

</details>

#### 2. 袋外资格

用 B 训练过的树能否参加 B 的袋外预测？

<details><summary>答案与解释</summary>

不能。袋外资格针对记录与具体树这一对，必须排除直接用该记录训练的成员。

</details>

#### 3. 依赖数据

同一病人的十条记录分散抽样，能自动代表新病人上的误差吗？

<details><summary>答案与解释</summary>

不能。训练和评估可能共享病人特征，应按病人等合适单位处理依赖与划分，再解释评估对象。

</details>

### 从条件一步步推导

1. 每次抽样漏掉某样本概率1−1/n，独立抽n次后为(1−1/n)ⁿ。
2. n很大时接近e⁻¹≈0.368；不同树的袋外集合不同。

### 具体输入与计算步骤

原样本A、B、C、D，抽到A、A、C、D。

1. n=4时，一点全程未抽中概率(3/4)⁴=81/256≈0.3164。
2. 期望不同样本数4×(1−81/256)=2.7344，不是必定恰好3个。

计算结果：期望不同样本数4×(1−81/256)=2.7344，不是必定恰好3个。

### 换到实际问题中应用

用随机森林估计泛化误差。

1. 对每个训练样本只汇总未训练过它的树的预测。
2. 再与真实标签比较形成袋外分数；所有预处理也须避免利用评估标签。

应用结论：再与真实标签比较形成袋外分数；所有预处理也须避免利用评估标签。

### 原有解释与进一步例题


### 定义

统计自举（bootstrap）从已有样本中有放回地重抽样，用重抽样结果估计统计量的抽样变化。随机森林还用自举训练不同树；某棵树未抽到的原样本称为该树的袋外样本（OOB）。它与逐段解利率曲线的“自举”是不同方法。


### 参数与公式

从 n 个独立同分布观测中抽 n 次，一个指定观测未被抽中的概率为 $(1-1/n)^n\to e^{-1}$。每次重抽样得到统计量 $\hat\theta^{*(b)}$，用 B 次结果的分布近似其抽样不确定性。金融时间序列有依赖时，通常需要区块等保留依赖的重抽样，不能直接打散日期。


### 例子

原样本为 A、B、C、D，一次自举可能抽到 A、A、D、B，C 是这次的 OOB。用多个重抽样均值的标准差估计均值的不确定性；OOB 预测则只汇总未训练过该观测的树，不能把训练过它的树也加进来。


### 适用边界与常见误解

Out-of-bag evaluation does not replace appropriate temporal or group-based validation.
