## 建立 CS 到 AI 的整体地图

先读领域导览：01 → 02 → 04 → 05 → 07 → 14 → 17 → 19 → 21 → 25 → 30 → 37 → 40 → 48 → 51 → 52 → 54 → 57 → 59 → 62 → 65 → 69 → 72。

之后依据[完整索引](../cs_ai_v2_index.md)补对应细讲。不要因导览里出现了一个缩写，就认定已经掌握算法细节。

## 准备机器学习基础交流

21–24 建立数据与任务语义，25–29 比较监督学习算法，30–36 理解无监督、概率与序列方法，37–39 检查验证与因果边界。最后练习 [75](../chapters/75.md)、[77](../chapters/77.md)、[78](../chapters/78.md) 讲。

比较方法时固定四个维度：数据假设、训练目标、预测成本、失效条件。例如，随机森林与 Boosting 的区别要落到构造模型的方式，而不只是说哪个更强。

## 理解 LLM、Agent、VLA 与世界模型

先补 22、40–47 的训练基础，再读 52–61，最后读 65–73。Transformer、训练目标、检索系统与工具执行属于不同层次，应逐层区分。

特别复习四组区别：注意力与 KV cache、微调与 RAG、离策略与离线 RL、视频预测与动作条件世界模型。用 [76](../chapters/76.md) 和 [78](../chapters/78.md) 讲检查自己能否解释边界。

## 口述自测

每次挑 5 道题，先不看答案说 30–60 秒，再对照解释。为自己标记：能定义、能举例、能比较、能说局限。不要用“听过名称”代替“能够实现”，也不要背诵与自己经历不符的项目描述。
