## Mathematical checks and edge cases

For sorted robot positions a ≤ b and assigned targets c ≤ d, a crossing assignment has distances |a−d| and |b−c|. Put M=max(|a−d|,|b−c|). The inequalities a−M ≤ c ≤ a+M and b−M ≤ d ≤ b+M follow from the ordering and the two crossing bounds. Therefore replacing crossing assignments by a→c, b→d cannot increase the largest displacement. Repeated uncrossing proves that matching equal ranks succeeds whenever any perfect threshold matching exists. Checking that each new position has some old neighbor fails to enforce distinct old robots; `[0,4]` to `[0,1]` is the counterexample.

For the cooldown formula, N is a throughput lower bound. The f occurrences of each most-frequent label require f−1 separating blocks of length at least n+1; the m final occurrences give the second bound `(f−1)(n+1)+m`. Filling the blocks with the remaining labels gives that bound when idle slots remain. When enough other tasks fill or enlarge all blocks, all N slots can be occupied. This argument assumes the exact unit-duration, reorderable, uniform-cooldown model above.

For signed subarrays, a candidate i is dominated by later j whenever P[j] ≤ P[i]: every future endpoint gets at least as large a sum and a strictly shorter interval from j. Once i forms a feasible interval with the current endpoint, future endpoints cannot improve that particular start's length, so it can leave the front. These are different deletion reasons. Prefix differences and distances must use an integer type wide enough for accumulated values.

`scripts/check-english-original-algorithms.mjs` reads every published algorithm example, compares it with a direct/exhaustive reference, and checks risky efficient recurrences against independent bounded models. Coverage includes all binary snapshot pairs through width 6, exact wildcard matching, directed shortest paths against Floyd–Warshall, minimax grid paths against threshold reachability, disjoint-set cycle detection against edge removal, KMP against direct substring comparison, signed shortest subarrays against interval enumeration, rank compression against pair counting, and cooldown counts against state-space scheduling.
